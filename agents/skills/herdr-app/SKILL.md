# herdr-app

Always read `~/.config/herdr-app/AGENTS.md` first. That is Herdr's own guide
to layouts, mods, commands and the look; its type files (`gpui-kit.d.ts`,
`herdr.d.ts`) are the truth about the API — don't guess a style method or an
argument. Then follow the repo-local `herdr-app/AGENTS.md` as well.
